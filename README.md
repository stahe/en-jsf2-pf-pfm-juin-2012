## 📘 Overview

This project accompanies a course dedicated to:

* **JavaServer Faces 2 (JSF2)**
* **PrimeFaces**
* **PrimeFaces Mobile**

The goal is to build a complete **appointment scheduling** application, adapted to multiple technical environments.

This document is intentionally pragmatic: it presents only the elements necessary for building the applications under study.

---

## 🏗️ Applications Developed

The application is developed in the following environments:

1. **JSF2 / EJB3 / JPA** on *Glassfish 3.1*
2. **JSF2 / PrimeFaces** (Ajax-enabled version)
3. **JSF2 / PrimeFaces Mobile**
4. Porting each version to **JSF2 / Spring / JPA** on *Tomcat 7*

➡️ Total: **six Java EE applications**.

---

## 🎯 Learning Objectives

* Understand the JSF2 architecture
* Work with PrimeFaces components
* Integrate JPA and EJB3
* Compare a complete Java EE configuration with a Spring / Tomcat architecture
